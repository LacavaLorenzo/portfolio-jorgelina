# Carpeta de imágenes

Cada trabajo tiene su carpeta. Si subís una imagen **con el mismo nombre** que una que ya está, la reemplaza sola en la web.

| Carpeta | Dónde aparece |
|---|---|
| `500rpm/` | Galería deslizable del caso 500 RPM (posteos, stories y un copy) |
| `dicuore/` | Copys de las escuelas y de Esclavas (pestañas de Di Cuore) |
| `pettunias/` | Proyecto Pettunias: posteos, carrusel, etiquetas y el reel (`reel.mp4`) |
| `nadia/` | Dra. Nadia Disanti: tarjeta, recetario y carpeta |
| `cine/` | Opinando a Primera Vista y Argentriunfos |
| `foto.jpg` (suelta acá) | Tu foto en "Sobre mí" |

Para **agregar** una imagen nueva a una galería hay que sumar una línea en `index.html` (copiá una de las que ya están y cambiale el nombre del archivo y el texto).

Tip: que pesen menos de 500 KB (exportá desde Canva como JPG).
